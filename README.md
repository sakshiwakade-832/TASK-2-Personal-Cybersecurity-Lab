# Cybersecurity Lab Setup Using Kali Linux and DVWA

## Project Overview
This project demonstrates the setup of a cybersecurity lab environment using kali linux and DVWA.This lab is designed for learning Ethical Hacking, Vulnerability assessment, Network analysis, and Web application security testing in a safe and isolated environment.

## Objectives
- Set up virtual cybersecurity lab
- Configure Kali Linux as the attacker machine.
- Deploy DVWA as the target application.
- Verify network connectivity.
- Perform port scanning using Nmap.
- Intercept web traffic using Burp Suite.
- Capture and analyze packets using Wireshark.

## Tools Used
- Kali Linux
- DVWA
- VirtualBox
- Nmap
- Burp Suite
- Wireshark

## Project Architecture
Kali Linux (Attacker)
          |
  Virtual Network
          |
    DVWA (Target)

## Steps Performed
1. Installed Kali Linux in VirtualBox.
2. Configured NAT nad Host-Only networking.
3. Installed and configured DVWA.
4. Verified connectivity using Ping.
5. Performed network scanning with Nmap.
6. Intercepted traffic using Burp Suite.
7. Captured packets using Wireshark.
8. Documented findings and observations.
